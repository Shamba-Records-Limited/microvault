Daraja

Record a C2B confirmation

Record a settled C2B payment as an observation for the poller to confirm

path Parameters
slug
required
string

Callback slug

Request Body schema: application/json
required

Confirmation notification

BillRefNumber
string

BillRefNumber is the account reference the payer typed, exactly as entered.

BusinessShortCode
string

BusinessShortCode is the paybill/till the payment was made to.

FirstName
string

FirstName is the payer's first name as held by Safaricom.

InvoiceNumber
string

InvoiceNumber is an optional invoice reference; usually empty for C2B.

LastName
string

LastName is the payer's last name as held by Safaricom.

MSISDN
string

MSISDN is the payer's phone number.

MiddleName
string

MiddleName is the payer's middle name as held by Safaricom.

OrgAccountBalance
string

OrgAccountBalance is the shortcode's balance after this transaction, as a decimal string.

ThirdPartyTransID
string

ThirdPartyTransID is echoed back from our validation response, present only on the confirmation callback.

TransAmount
string

TransAmount is the payment amount in KES, as a decimal string.

TransID
string

TransID is Safaricom's unique receipt number for this payment.

TransTime
string

TransTime is the payment timestamp as YYYYMMDDHHmmss.

TransactionType
string

TransactionType is Safaricom's transaction type, e.g. "Pay Bill" or "Buy Goods".

Responses

https://localhost:8080/api/v1/callbacks/daraja/{slug}/c2b/confirmation

Webhooks

Process YellowCard Payment Webhook

Handle incoming webhooks from YellowCard payment service

header Parameters
X-YC-Signature
required
string

HMAC signature for verification

Request Body schema: application/json
required

Webhook event data

apiKey
string

APIKey is the YellowCard API key the payment was created under.

errorCode
string

ErrorCode is set when Status indicates a failure.

event
string

Event names the webhook event type, e.g. PAYMENT.CREATED, PAYMENT.COMPLETE.

executedAt
integer

ExecutedAt is the Unix timestamp (seconds) at which this event occurred.

id
string

PaymentID is YellowCard's own identifier for the payment.

sequenceId
string

SequenceID is the idempotency key we supplied when creating the payment; used to look up the local loan/transaction.

sessionId
string

SessionID is YellowCard's session identifier for this payment attempt.

object

SettlementInfo carries on-chain settlement details once available; never nil after unmarshalling, check its fields for presence.

status
string

Status is YellowCard's payment status at the time of this event (e.g. created, pending_settlement, processing, complete, failed).

Responses

https://localhost:8080/api/v1/webhooks/yellowcard
